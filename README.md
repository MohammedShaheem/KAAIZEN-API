# KAAIZEN-API

A RESTful API backend built with **Python**, **Django**, and **Django REST Framework (DRF)** for fitness and lifestyle applications.  
It provides endpoints for managing users, workouts, nutrition, trainers, and admin features.

##  Features

Full-featured Django REST API including:

- User authentication & registration
- Workout management (create, update, list, delete)
- Nutrition data endpoints
- Trainer related endpoints
- Admin API for overview and control
- Modular Django apps (`users`, `workouts`, `nutrition`, `trainers`, `core`, and more)

##  Tech Stack

✅ Python  
✅ Django  
✅ Django REST Framework  
✅ SQLite / PostgreSQL (configurable)  
✅ JWT / Token authentication  
✅ Environment based configuration
